# Genomic Weights Experiment Visualisation

An interactive visualisation of the evolutionary strategies (Direct, Flat, Hierarchical and Topological) tested in the [Genomic Weights Thesis](https://github.com/guruswami-ai/GenomicWeightsThesis).

The thesis asked whether genomic compression ideas could be applied to LLM weights. The hypothesis was refuted; the full negative result, method and adversarial review are in the thesis repository. This visualisation was built along the way as a tool for understanding a field we knew nothing about at the start: computational biology.

## Run it locally

```bash
npm install
npm run dev
```

Built with React, Recharts and three.js (via React Three Fiber), bundled with Vite.
